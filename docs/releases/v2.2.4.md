# v2.2.4

Environment Setup handles explicit plugin lifecycle/account changes and confirmed local blockers
for the current task. Ordinary work reuses its configuration; setup-tool visibility and optional
KB or dependency warnings do not start repair. Dependency recovery targets the affected service
and opens account settings only when an account update is needed.

Build keeps Conan and compilation failures. Explicit toolchain installation routes to the separate
`openubmc-env-init` specialist when available; generic environment/configuration wording no longer
routes builds to plugin setup. Debug distinguishes account failures from transport and device errors.
