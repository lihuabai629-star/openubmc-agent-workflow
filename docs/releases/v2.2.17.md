# 2.2.17

`observe` preserves `lsclass`, `lsmc` and `lsobj` MDB discovery output up to
16 KiB and 512 lines across both projection passes, recording source/returned
counts and `projection_complete`. Oversized discovery results cut only at token
boundaries and mark `projection_truncated` with explicit follow-up guidance.

`observe` schema and preflight guidance separate `capability` (`names` only) and
`mdb` (`queries` only) selectors, returning a ready-to-use split `next_action`
when `queries` are mistakenly placed on a `capability` selector.

BMC observations, diagnosis, bundle collection and delivery resolve BMC
credentials without requiring associated OS credentials unless an explicit OS
path is requested.
