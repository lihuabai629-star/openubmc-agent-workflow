# v2.2.3

`openubmc-code-submit` selects internal GitLab or community GitCode from the
repository's actual push and upstream endpoints. It carries source, build and
QEMU validation into commit, personal-fork push and MR/PR delivery. Internal
MRs follow repository identity and formatting; community contributions retain
Issue, CLA, CI and explicit public-content confirmation rules.

The package includes a read-only submission checker, local platform routing,
and GitCode API commands for repository/branch reads, paginated PR lists,
cross-fork PR creation and title/body updates. Writes preview the complete
target and payload; confirmation digests bind the same content. Remote checks
use the push URL even when a fetch mirror differs, and reject multiple targets.

The full profile contains 13 workflow Skills plus packaged Runtime support.
Source submission uses Git and platform APIs; Runtime Gate ownership and Conan
package publication remain with their existing owners.
