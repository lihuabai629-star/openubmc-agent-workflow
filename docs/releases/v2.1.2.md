# 2.1.2

Created-target Live Patch rollback now omits the absent backup path while retaining
the expected-current checksum guard. Runtime restart recovery also accepts a valid
typed recovery disposition loaded through a second module identity; plain strings
and unknown values remain invalid.

Explicit Bingo commands and Bingo CLI source changes now route to Skills included
in the plugin package. Their public route receipt checks the owning workspace and
requested artifact before allowing execution. Product publication requires an
explicit board and the stable release command remains:

```bash
bingo build -t publish -b <board> -bt release --stage stable
```

Plugin assembly enforces a 128 KiB budget for packaged Skill instructions and
Agent metadata so routing additions cannot grow the initial prompt catalog without
a release failure.
