# v2.2.2

The packaged QEMU owner now includes the x86 development workflow proven by the
26.12 and migrated 26.06 trials. Build hands off a complete launch index and
artifact identity; QEMU Testing defines fresh-runtime selection, task-owned
process and port control, bounded first-boot recovery, layered business smoke,
healthy development baselines, fault-injection recovery, and a 120-second
stability window.

`qemu_workflow_contract.py` checks plan fields and current artifact hashes,
rejects incomplete service coverage, and binds measured stability and guest
identity to the result. Existing Runtime evidence storage may retain that
validated receipt; QEMU process control stays in repository launchers. The
plugin still excludes Bingo build and Bingo CLI development entry points.
