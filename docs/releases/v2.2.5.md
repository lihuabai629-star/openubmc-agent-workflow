# 2.2.5

Dependency repair replaces a drifted capability cache. Setup recovery distinguishes
dependency, package-integrity and configuration failures.

KB MCP 1.3.2 coordinates token refresh across local clients using Linux `flock`.
Account/configuration revisions have separate caches, and late authentication
failures cannot invalidate a newer token. Locks recover on process exit.

QEMU validation requires RFC3339 observation windows and protocol-specific modes.
Historical validation is explicit and cannot establish current readiness.
`execute(kind=attach_qemu_evidence)` attaches a verified, Run-bound bundle while
preserving the current Gate and Outcome. Existing receipts missing freshness or
mode bindings require a new plan and observations before current acceptance.

Conan publication binds recipe revision, package ID and package revision, with
local and remote identity checks. Build routing separates failure diagnosis,
component commands, product outputs and later publication.

Remote collection hands local bundles to their dedicated analyzer. Installed
reference files remain immutable; credential guidance uses private local
resolution. Test design reuses repository and task context before requesting
missing information.
