# 2.1.8

Codex desktop can discover openUBMC as a global MCP application and open its
workflow and knowledge-base panel from the native sidebar. The companion adapter
connects its read backends only when a read is requested. HTTP mode also supports
ChatGPT MCP Apps with OAuth and a protected local preview.

Dependency verification walks each directory once and reuses its filesystem
metadata. Every file is still hashed, internal links retain their original
inventory entries, and links escaping the dependency cache remain rejected.
