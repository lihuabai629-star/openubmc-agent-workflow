# v2.2.1

The supported backend is Linux or WSL, with bmcgo as the build entrypoint.
Windows clients can forward stdio to an explicitly selected WSL installation;
native Windows Python, SSH, ACL and process adapters are retired.

The full profile contains twelve business Skills. The separate Bingo build,
Bingo CLI development and Lua compatibility Skills are retired; Lua guidance
remains in Developer. QEMU, package publication, community checks, documentation
review and offline log analysis remain available. Model planning stays as
experimental source and is excluded from the runtime package.

The package includes a Codex global panel entry, knowledge-base chat and a
protected loopback preview. The public ChatGPT HTTP/OAuth connector is removed.
The panel exposes only bounded reads and cannot retry Runtime mutations.

KB authentication recovery refreshes expiring credentials and preserves typed
failures when interaction is required. Runtime fixes preserve diagnostic source
provenance, systemd verification, Live Patch health receipts, phase handoffs,
negative build routing and task closeout evidence.

This is a local development version. The historical release lock does not
qualify v2.2.1 as a published release.
