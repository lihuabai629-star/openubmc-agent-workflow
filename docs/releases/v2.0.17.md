# 2.0.17

A target account entered in the local browser is remembered for its exact IP,
purpose and transport only after a successful strict connection check. Failed
authentication, trust checks and configuration races leave the active account
unchanged; account values do not appear in the task-facing receipt.

After a user confirms that a BMC IP and OS IP identify one device, the Agent can
store that address association without reopening settings. Repeating the same
pair is idempotent. Replacing another OS association requires the previously
linked address and a fresh confirmation. The association supplies an address;
it does not verify OS credentials or authorize an OS connection.
