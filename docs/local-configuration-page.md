# 本机配置页面

在 Codex 中说“打开 openUBMC 本机配置”，环境 Skill 会启动本地页面。页面只监听本机地址，显示配置所在的 Linux／WSL 环境与文件位置。

BMC 与 OS 页面先建立凭据记录，再将它们选为各协议的全局默认。同一条记录可用于多个明确选择的用途；按 IP 覆盖使用完整记录。密码不显示在编辑框中，修改时选择保留、替换或移除。SSH 密钥使用已有本地文件路径。

会话中需要记住某台设备的账号时，页面顶部的“连接并记住这台设备”可填写 IP、用途、协议、用户名和密码。页面仅在该目标的严格连接检查成功后，为当前用户保存并激活此 IP 的覆盖记录；后续任务会自动选择该记录。认证失败、超时、主机身份或 TLS 校验失败时不会保存。用户应在本机页面输入密码，不要在聊天中粘贴；已经进入会话记录的密码按凭据暴露流程轮换。

“保存”保留待生效配置；“保存并生效”让后续请求使用新配置。已有请求继续使用其原版本。“导入已有配置”读取当前选定的旧文件，原文件保留。两处同时编辑时，过期保存会被拒绝，刷新后再修改。

连接检查分别记录目标、协议与结果。没有 IP 时不会探测设备。SSH 检查需要可信主机身份，Redfish 检查验证服务端证书。Conan 仅认证已有 remote，成功后构建使用 Conan 的当前用户缓存；更换构建用户或容器后需在对应环境检查。KB 验证码或浏览器授权需求会显示为需要人工操作，不会报告为已验证。

页面关闭后，配置仍保存在当前用户目录。页面会话 URL 仅用于本机访问，重新打开页面会产生新的会话。原生 Windows 页面及跨 WSL 实例访问尚未完成资格验证。
